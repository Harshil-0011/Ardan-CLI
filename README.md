# Ardan CLI Project

This repository contains the source code for Ardan, an autonomous coding agent CLI powered by Ollama.

## Quick Start

1. Ensure Ollama is running.
2. Install with `pip install -e .` from this directory.
3. Run: `ardan run "Build a simple web server in Python"`

## Project Structure

- `ardan/`: The main Python package containing the agent, tools, and UI.
- `config.yaml`: Default configuration file.
- `pyproject.toml`: Project metadata and dependencies.
- `requirements.txt`: List of required Python packages.

See the detailed `README.md` inside the `ardan/` directory for full documentation.
